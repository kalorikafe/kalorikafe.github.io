# scripts/oneoff/

senkronu). Kalıcı üretim hattı `scripts/build-images.mjs` + `npm run
images:build`; doğrulama `images:audit`. Bu dosyalar hiçbir npm script'ine
bağlı değildir; tekrar çalıştırılmaları beklenmez. Silinmeden önce geçmiş
kaydı olarak burada tutulurlar.
