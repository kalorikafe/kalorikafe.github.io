# 📋 Original Request & Project Milestone Log

## User Vision
Türkiye'deki tüm popüler zincir kafelerin (Starbucks, Espressolab, Kahve Dünyası, Caffè Nero, Coffy, Mackbear, Arabica, Gloria Jean's, David People, Tchibo) menülerindeki içecek ve yiyeceklerin makro değerlerini (kalori, protein, karb, yağ, şeker, kafein) ve alerjen uyarılarını gösteren, son derece şık, rahat kullanılabilir, yüksek kontrastlı ve lüks Web Aggregator uygulaması.
